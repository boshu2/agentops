## Highlights

AgentOps 3.11 is a skills release. It adds three skills, bringing the menu to
32, and changes 28 of the 29 existing skills, mostly by folding in methods from
a survey of other public skill libraries, each rewritten in AgentOps terms. No
command or skill name changes.

The new skills:

- **Triage** turns an incoming bug report, feature request, external PR or
  alert into a decision backed by evidence. For accepted work it writes a brief
  an agent can act on without the conversation.
- **Architecture** finds where a codebase's structure makes change expensive and
  compares interface designs before any code moves.
- **Ergonomics** checks whether an agent can discover a CLI, API or tool, read
  its output and recover from its errors.

Unlike 3.10, this release ships no evaluation. None of the skill changes has
been measured with Skill Eval or the plugin evaluator, so treat them as guidance
to try, not a measured improvement. Skill bodies are about a third longer than
in 3.10, which costs context each time a skill loads.

Two other changes reach users. The Claude Code plugin installs from a generated
`plugin/` folder that holds only what the plugin loads. And `ao`'s help and
briefing text now states the 3.9 review rule instead of the retired one.

## Upgrade Notes

- Update the plugin, the npx install or Homebrew as usual. Every 3.10 command
  and skill name still works, and nothing needs migrating.
- The Claude Code plugin's marketplace entry now points at `./plugin`. Install
  and update commands are unchanged.
- The plugin no longer puts `bin/factory` and `bin/ralph` on the Bash `PATH`.
  They are operator tools; run them from a repository checkout.
- Research no longer pre-approves Bash and Write. Expect a permission prompt
  where it runs a command or writes a file, as with the other skills.
- With the plugin's hooks on, expect a permission prompt when an agent writes
  `~/.agents/ao/policy-waivers`. Approve it only for a waiver you asked for.
  Prefixing one command with `AOP_WAIVE=` never waived a policy; set it in the
  environment Claude is launched with instead.
- In a source checkout, run `git pull --ff-only`, then rerun `ao skills link`
  with the selectors you used before. Add `--skill triage --skill architecture
  --skill ergonomics` for the new skills. Without selectors it links every skill
  in the library.
- A plugin update replaces the installed copy of every skill. If you changed
  skills in place, move those changes to a fork or a source checkout first. The
  README's "Make it yours" section shows how.
- Upgrading from 3.9 or earlier: read the
  [3.10 release notes](https://github.com/boshu2/agentops/blob/main/docs/releases/2026-10-05-v3.10.0-notes.md)
  first.

## Product Areas

### Skills and Workflows

- Added: Triage, Architecture and Ergonomics, described above. None has been
  measured with Skill Eval yet.
- Changed: A survey of other public skill libraries added methods to nineteen
  skills. Doc brings documentation current after a change, describes a change
  for reviewers and writes release notes for a range. Research checks a
  document's claims by re-deriving them another way and treats an empty search
  as absence only when it could have matched. Security reviews what actually
  ships for a publish question and covers CI definitions. Validate counts green
  obtained by changing the subject or the gate as weakened acceptance. The
  [changelog](https://github.com/boshu2/agentops/blob/main/CHANGELOG.md) lists
  the rest.
- Changed: A second pass read every line of the two public skill libraries
  closest to AgentOps. 173 methods survived a check against current skill text
  and went into 27 skills. Implement confirms the failing run executes the code
  in question and repairs a defect class rather than one instance. Test derives
  expected values from a specification, never the code under test. Review binds
  the subject to the merge base and holds a finding under pushback unless new
  evidence arrives.
- Changed: Doc, Implement, Security and Test gained optional references for
  developer journeys, difficult failures, attacker-path evidence, exploratory
  QA, suite audits and workload performance.
- Changed: Agent Native's per-packet result and Orchestrate's status line report
  the last observed activity. RPI names a stall by category and the fact
  observed, with no counts. Plan writes into existing intent only with authority
  and otherwise proposes an amendment.
- Changed: Using GC's Mayor template no longer pushes or opens a PR unless
  publishing is authorized.
- Changed: The `implement-wave` workflow runs its implementer lanes one at a
  time in the caller's working tree, so a wave takes the sum of its lane times.
  Arguments and the result shape are unchanged.
- Fixed: Research no longer pre-approves Bash and unscoped Write through
  `allowed-tools`.
- Fixed: Retired review-rule wording (a fresh read and repair on every change)
  is gone from Doc's references, and Domain's shipped Go standard no longer
  states AgentOps contributor facts as general guidance.

### CLI and Operator Commands

- Changed: `ao --help`, `ao quick-start`, `ao demo` and `ao robot-docs` state
  the review rule from 3.9: checks and CI gate an ordinary change, and one fresh
  read happens only where a mistake is costly. The 3.10 binary still printed the
  retired rule that every change needs a fresh judgment.
- Fixed: `ao doctor fix` keeps the run ID, the actions it applied and the backup
  paths in its error output when it cannot write its report. It still exits 74,
  so you can inspect or undo before retrying.

### Install, Upgrade, and Distribution

- Changed: The Claude Code plugin installs from `plugin/`, a generated folder
  that holds skills, agents, the policy hook dispatcher, Workflow tool scripts,
  the manifest and a new listing icon. `scripts/regen-plugin-tree.sh` builds it,
  and `scripts/regen-all.sh --check` fails when it is stale.
- Changed: The plugin no longer puts `bin/factory` and `bin/ralph` on the Bash
  `PATH`.
- Changed: The release publisher waits for a green Validate run on the exact
  tagged commit before it publishes. `scripts/retag-release.sh` pushes main
  before it changes any tag or release.

### Codex and Runtime Integrations

- Changed: The Codex plugin reads the same `skills/` tree, so it carries the
  three new skills and every skill change above. Its manifest and layout are
  otherwise unchanged.

### Hooks and Lifecycle

- Added: The plugin's guard asks before an agent writes the policy waiver file,
  `~/.agents/ao/policy-waivers`, with a redirect, `tee`, a copy, an in-place
  edit, or Edit or Write. Approve only a waiver you asked for. It makes such
  writes visible; it is not tamper-proofing, and other writers or a relocated
  waiver file are not caught.
- Fixed: The hook installer no longer says to prefix one command with
  `AOP_WAIVE=<policy-id>`. That never waived dispatcher policies, because the
  hook reads its own environment. Set `AOP_WAIVE` in the environment Claude is
  launched with, or add a `<policy-id> <expiry-unix-epoch>` line to the waiver
  file.
- Fixed: The hooks tree no longer contains an `npx` launcher string, which the
  Claude Code plugin marketplace validator reported as blocking.

### Eval, Validation, and Release Gates

- Changed: Validate's `summary` check fails when a lane is cancelled or times
  out, and a full run fails on any skipped lane.
- Changed: Two gates that could not fail, `always.mutation-route` and
  `always.file-manifest-overlap`, are retired.
- Changed: The RPI plugin-eval criterion c3 grades the conditional review rule,
  and two core eval cases expect the current rule.
- Changed: The skill evaluator step in CI stays on Python 3.14, because Harbor's
  `litellm` dependency has no Python 3.15 release.

### Docs and Onboarding

- Changed: The README's "When you need to…" table lists Triage, Architecture
  and Ergonomics.
- Changed: The upgrade guide, the vocabulary and bounded-context contracts, the
  trust-factory page, the component map and the kernel template state the
  current review rule. ADR-0017 records it as a dated amendment and marks the
  passages it superseded.

### Security, Privacy, and Supply Chain

- Changed: Go toolchain 1.27.3, `golang.org/x/text` 0.43.0, golangci-lint
  2.14.0 and updated GitHub Action pins, including the Claude Code Action and
  GoReleaser Action.

### Contributor/Internal Refactors

- Changed: `AGENTS.md` has a 14,336-byte budget on top of its line limit, and
  the Go and Python rules files load only for their own paths.
- Changed: The PR template asks authors to repeat gate trailers in the
  description, because squash merges use the PR body.

## Known Issues

- No skill change in this release has been measured. Skill Eval, the plugin
  evaluator and the probe runner were not run on 3.11, and Architecture and
  Ergonomics show as unmeasured in probe coverage. The 3.10 evaluation results
  do not carry over.
- Skill bodies are about a third longer than in 3.10, and references grew by
  about a fifth. A loaded skill costs more context than before.
- The 3.10 known issues were not re-measured and may still apply, including
  skills that did not load on a blind request. See the
  [3.10 release notes](https://github.com/boshu2/agentops/blob/main/docs/releases/2026-10-05-v3.10.0-notes.md).
