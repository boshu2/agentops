## Highlights

AgentOps 3.12 says what the project is and cuts the catalog to match.

**Software engineering practice, re-tested for AI agents.** The new
[practice ledger](https://github.com/boshu2/agentops/blob/main/docs/practice-ledger.md)
lists which practices held up when agents did the work, which hold in a
different shape, which did not survive, and which are still being tested, each
with the evidence behind it. The README, product page and docs index now open
with that sentence.

Every skill was then read against the ledger and against a written bar for what
a good skill is. The catalog goes from 32 skills in 3.11 to 28:

- **Reverse Engineer is removed.** It had no measured gain and no ledger row.
  Its evidence rules moved into Research.
- **Using GC is removed.** It was an adapter for a factory setup the ledger
  lists under "Did not survive". Gas City ships its own operator skills.
- **Agent Native is merged into Orchestrate.** Checking worker packets,
  launching them and reporting each result is one job with coordination.
- **Reality Check is folded into Research**, as its claimed-state audit. That
  happened on main just after 3.11 and reaches users in this release.

Twenty-four of the remaining skills changed. Domain lost about 1,800 lines of
generic language standards and now sends an agent to your repository's own
rules, config and CI. Doc lost about half its references. Test and Refactor
state the form of test-driven development that held up: a test that fails
without the fix, then refactor, with no required order. Validate, Council and
Premortem no longer imply repeated review rounds.

This release also carries the October repair waves (several hundred confirmed defects
fixed across all skills) and the measurements published since 3.11. The
catalog audit itself was not measured: no evaluation was re-run on the reshaped
skills.

## Upgrade Notes

- Update the plugin, the npx install or Homebrew as usual. In Claude Code, if
  `claude plugin update` reports no change, uninstall and reinstall the plugin
  to refresh its copy.
- Four skill names are gone. Use Orchestrate where you named `agent-native`,
  Research where you named `reality-check` or, for an adoption question,
  `reverse-engineer`, and Gas City's own skills where you named `using-gc`. The
  3.11 text of all four is in Git at tag `v3.11.0`.
- New installs do not remove obsolete copies. If you installed with npx or
  linked skills from a source checkout, remove the four old skill directories
  from your agent's skills folder yourself.
- `ao workflows` and `scripts/install-workflows.sh` are removed, and the plugin
  ships no Workflow tool scripts. Links under `~/.claude/workflows/` or
  `.claude/workflows/` now point at deleted files; see
  [Removed workflows](https://github.com/boshu2/agentops/blob/main/docs/install-day2-ops.md#removed-workflows-claude-code)
  for the cleanup.
- Domain no longer ships language standards. If you relied on
  `skills/domain/references/standards/`, copy the files you want from
  `v3.11.0` into your own repository's rules.
- Idea Genie returns its result inline and writes a file only where you name
  one. It no longer writes under `.agents/scratch/ideas/` by default.
- RPI no longer offers an `rpi-report.v1` file, and the schema is removed. A
  persisted result, when you need one, is Validate's `verdict.v2`.
- Memory saves a note after you approve it. Asked to save unread, it gets one
  fresh read first; if neither can happen it returns the draft and says it was
  not saved.
- `ao gc check` no longer requires the `using-gc` skill in a city or rig.
- In a source checkout, run `git pull --ff-only`, then rerun `ao skills link`
  with the same `--skill` and `--dest` flags you used before. Without `--skill`
  it links every skill, and without `--dest` it links into every installed
  runtime.
- A plugin update replaces the installed copy of every skill. If you changed
  skills in place, move those changes to a fork or a source checkout first.
- Upgrading from 3.10 or earlier: read the
  [3.11 release notes](https://github.com/boshu2/agentops/blob/main/docs/releases/2026-10-22-v3.11.0-notes.md)
  first.

## Product Areas

### Skills and Workflows

- Added: Skill Builder's authoring doctrine has a "Shape the body" section: open
  on the one thing the skill makes a run do differently, order material by how
  many runs reach it, put known mistakes first, state the sign that it worked,
  keep one name per concept.
- Changed: Orchestrate now owns the packet check (canonical write scopes
  compared before any launch), launch and observation, and the per-packet
  result with its `not_as_briefed` line for steps a worker refused, held,
  worked around or left unverified. Its description changed to cover launching;
  that line is unmeasured.
- Changed: Domain has a "Conventions lookup" that cites the repository's own
  instruction files, path-scoped rules, linter config and CI, and reports a
  conflict instead of applying a general language guide.
- Changed: Test's `tdd` mode accepts either order. The proof is a test that
  fails without the change, shown by running it first or against the
  pre-change code. Four generic technique references are removed.
- Changed: Refactor states that restructuring under a green result is the step
  that held, and says when to use it instead of Implement.
- Changed: Validate confirms a repair with the checks that cover it and does
  not start a second judgment. The rule that an author cannot issue its own
  PASS is unchanged. Cross-model dispatch rules and judgment receipts now live
  under Validate.
- Changed: Premortem's first check fires only for a costly unit that nothing
  but its author's checks verify. An ordinary change graded by its author's
  tests and CI is no finding.
- Changed: Council's judge-split mode covers a split between the legs of one
  validation read. Its description lost one word to fit the length budget.
- Changed: Codex Exec runs a validator whose receipt is required without
  `--ephemeral`, because that flag writes no session file to cite.
- Changed: Implement, Triage, Research, Doc, Premortem and Idea Genie moved
  material that only some runs need behind links that say when to open them.
- Changed: Skill Eval screens each case for headroom first and names the model
  and harness a result holds for.
- Changed: Skill Builder says what runs without `ao`: `audit.sh` and `heal.sh`
  need it; the template and doctrine do not.
- Changed: Security, Ergonomics, Navigate and Craft Goal carry fixes verified
  on their evaluation cases, listed in the
  [changelog](https://github.com/boshu2/agentops/blob/main/CHANGELOG.md).
- Changed: Reality Check is folded into Research as its claimed-state audit.
- Removed: Reverse Engineer, Using GC and Agent Native, as described above.
- Removed: The Claude Code workflows. Run the same work through the skills.
- Fixed: Three repair waves closed the defects a per-skill review confirmed,
  including a path-containment check in Domain that accepted a sibling
  directory and commands in Security's checklist that printed secret values.

## Known Issues

- The catalog audit is unmeasured. No evaluation was re-run after it, so the
  figures in the ledger and README describe the skills before these edits. The
  reshaped skills most likely to differ are Doc (its handoff rules moved to a
  reference), Orchestrate (now carrying the packet check), Premortem and
  Security.
- Every measurement is on Claude Code with Claude Opus 5.5. Nothing is measured
  on Codex, Gemini, Cursor or another Claude model.
- Skills still load rarely unless you name them. Triage and Implement are the
  two with a measured description fix.
- Validate, Test, Research and Orchestrate score the same with and without the
  skill on the current cases, because the model already passes them.
- Domain, Architecture and Ergonomics show measured gains but map to no ledger
  row yet.
