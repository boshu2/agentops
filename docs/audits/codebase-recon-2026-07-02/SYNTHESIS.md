## What AgentOps is (one paragraph)

A hookless, in-session **verification membrane for coding agents**: it drives a stochastic agent from a goal to a *verified* done and refuses to call a change done until an independent, cross-family reviewer (never the author, never the same model) writes a CONFIRMED verdict that is bound into a hash-chained provenance ledger — **no verdict = not done**. Skills + a ~392K-LOC Go CLI (`ao`) + a repo-local `.agents/` corpus, across 6 DDD bounded contexts, running on Claude Code / Codex / Cursor / OpenCode. No daemon (ADR-0009); out-of-session work is delegated to a substrate (NTM + Agent Mail) that dispatches *whole skills* and is architecturally forbidden from decomposing the loop.

## The strongest signal in the repo

**The discipline is real, not marketing.** The single most-churned file across the last 200 commits is `docs/provenance/ledger.jsonl` (90 of 200). The repo enforces its own thesis on itself: every change lands a cross-family verdict. Corroborating: 4 TODO/FIXME in ~392K LOC, an empty `tests/_quarantine/`, and a self-assessment (README/GOALS/ADRs) that *demotes its own flywheel-moat claim to unproven* under a named structural headwind. This is a codebase that refuses to market ahead of its own ruler.

## The three things that matter most

1. **The core membrane has one live fail-open (audit A1).** `ao gate check` — the release authority — maps a missing/unlaunchable *blocking* backing script to `Unknown`, which is excluded from the failure computation, so it **silently passes**. Empirically proven. This is a membrane escape the membrane doesn't catch — precisely the class the product exists to eliminate, and precisely the escape-corpus feedstock ADR-0011 predicts. Compiling it into a fail-closed constraint would be the system dogfooding its own self-improvement.

2. **On this checkout the release hook is orphaned (audit A2).** `core.hooksPath` points at `.beads/hooks`, whose `pre-push` runs the *retired* `bd` shim, not `ao gate check`. So the two independent release-authority mechanisms (the gate's exit logic and the pre-push hook) both currently fail toward "allowed." Enforcement rests on manual `ao gate check --fast` + the CI backstop.

3. **~60 docs teach removed commands as live (audit A4/A5), and the gate that should catch it has a blind spot.** `ao rpi`/`orchestrate`/`evolve` were deleted (`f61c5f0e7`) but remain the canonical commands in flagship docs like `how-it-works.md`; the retired-tech gate's regex omits those verbs. The single highest-leverage fix in the whole run is one line in `scripts/check-docs-no-retired-tech.sh:43` — it converts an invisible ~60-doc drift into a self-catching gate.

## The deepest architectural truth

AgentOps solves "make stochastic work trustworthy" by reaching, again and again, for the **same four primitives** (pattern-extraction): hash-chained append-only tamper-evidence (5 packages), pure deterministic deciders over model *proposals* (planpawl/shape/constraints/evidenced-turn), fail-closed absence handling (6 packages), and drift-proof contracts generated by reflecting over the live artifact (capabilities/robot-docs/registries). The audit's headline bug (A1) is a *local violation* of the third primitive — which is exactly why it reads as a defect and not a design choice. The two highest-value extractions (`hashchain` and `atomicfile` helpers) would collapse ~5× and ~19× duplication of security- and crash-critical code into tested cores.

## Honest posture (unchanged from prior runs, re-verified)

- **Proven:** independent cross-family verification + a durable, tamper-evident verdict ledger. The receipts are public and derived from the ledger, not hand-written.
- **Still measuring:** whether the accumulated corpus makes the next session measurably better (the flywheel moat) — demoted to unproven under a data-starvation headwind (a competent membrane makes escapes structurally rare). The repo says so itself (ADR-0004, ADR-0011).
