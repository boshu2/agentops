# Operating loop (former name)

"Operating loop" was the former name for what is now documented as the
[RPI traversal](rpi-traversal.md). The old name described only the traversal —
one Plan -> Implement -> fresh Validate -> report-and-stop pass — and was
retired because AgentOps as a whole is the operations layer for agentic
engineering, not a loop.

The exact semantic contract lives at [rpi-traversal.md](rpi-traversal.md).
Historical plans, audits, releases, and evidence keep the old name; this page
exists so their links still resolve.
