## Trigger

A regeneration check in a fresh worktree classified only
`packs/agentops-executor/assets/generated-skill-manifest.json` as
`DIRTY_PRESERVE`. The generated bytes were identical, but the live checkout
mode was `0644` and the staged generator output mode was `0600`.

`scripts/sync-gc-pack.py` writes the manifest through `mkstemp` and atomic
replacement without setting the declared output mode. The worktree that
performed the earlier publication appeared clean only because its live
filesystem retained `0600`; Git records the file as `100644`, and the local
Git configuration does not surface that mismatch. A new checkout therefore
reproduces drift deterministically.

## Intent

Make the Gas City skill projection generator emit a stable, declared mode for
every generated file so publication identity survives a Git checkout.

## Acceptance

### T2M-1 — Stable generated-file mode

The manifest atomic-write path explicitly installs mode `0644`. Temporary-file
defaults and caller umask cannot alter the final declared mode.

### T2M-2 — Mode-aware generator proof

Focused tests begin with a wrong-mode manifest, run generation, and prove exact
bytes plus mode `0644`. Check mode detects a wrong mode rather than comparing
content alone.

### T2M-3 — Fresh-checkout convergence

A clean checkout of the repaired subject passes the transactional publication
check and `scripts/regen-all.sh --check` without relying on residual filesystem
state from an earlier write.

### T2M-4 — No projection regression

Gas City projection content, retired-destination behavior, source exclusions,
and all other owner targets remain unchanged. Focused tests, publisher tests,
projection parity, and the full regeneration check pass.

## Write scope

- `scripts/sync-gc-pack.py`;
- focused Gas City projection tests;
- this intent and later exact T2 evidence.

## Non-goals

- Do not change skill semantics or catalog behavior.
- Do not weaken the publisher's byte, mode, kind, or ownership checks.
- Do not encode worktree-local mode state in Git-independent publication
  receipts.
