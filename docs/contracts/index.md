# Contracts

The current public loop contracts are:

- [`subject-manifest.v1`](../../schemas/subject-manifest.v1.schema.json)
- [`verdict.v2`](../../schemas/verdict.v2.schema.json)
- [`rpi-report.v1`](../../schemas/rpi-report.v1.schema.json)

Deprecated compatibility contracts remain available for reading historical
artifacts only: [`plan-packet.v1`](../../schemas/plan-packet.v1.schema.json),
[`candidate-packet.v1`](../../schemas/candidate-packet.v1.schema.json), and
[`revision-packet.v1`](../../schemas/revision-packet.v1.schema.json).

The complete live contract inventory is generated in the
[documentation index](../documentation-index.md). A contract not present on
disk has no current authority; historical release notes may still describe it.
