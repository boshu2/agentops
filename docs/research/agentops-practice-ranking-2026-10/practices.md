# External evidence base: 125 agentic-engineering practices (October 2026)

Dated research snapshot, 2026-10-21. Repository state: `main` at a193b6bdf, after PRs #1217-#1221.
Five web-research lanes collected these practices in October 2026. This file is the external
evidence that the ranking, debate and changes in this directory rest on. Cite rows by their ID
(VG-nn, Enn, se-practice slug, AN-nn, PF-nn); sibling files use the same IDs.

## Summary

1. **Converged:** start with one agent and the simplest workflow. Add agents, skills or harness parts only when a measurement shows they help (VG-01, VG-04, E16, E18, PF-23).
2. **Converged:** the main quality lever is a runnable pass/fail check that the agent runs and shows. Must-hold rules belong in hooks and CI, because instruction prose is advisory (VG-06, VG-10, AN-06, AN-09, PF-20).
3. **Converged:** the author does not grade itself. Use one fresh evaluator where a mistake is costly, scoped to correctness and requirement gaps and grounded in executable evidence. Same-family judges still share bias (VG-13, PF-01, PF-02, E20-E22, AN-13).
4. **Converged:** context is a budget. Keep the always-loaded file short and non-inferable, load skills and path-scoped rules lazily, send exploration to subagents, and prune on each model change (VG-08, VG-17, E12, PF-09, PF-25, VG-20).
5. **Converged:** AI amplifies the delivery system. Use small batches, CI as the gate and rollback, and pair throughput with an instability countermetric. Self-reported speedups are not evidence (E03-E05, small-batches, ci-as-gate, goodhart-countermetrics, E01).
6. **Converged:** changes to the harness, skills and instructions are releases. Evaluate them against a no-skill baseline with negative controls, with eval noise smaller than any effect you act on (VG-18, VG-25, AN-11, AN-22, PF-21).
7. **Contested:** whether context files help at all, TDD inside the agent loop, multi-agent value at equal compute, LLM-judge reliability, how much human review remains, how heavy spec-driven process should be, and unsupervised loops on long-lived code. Details are in [Contested points](#contested-points-merged-across-lanes).
8. **No framework, AgentOps included, has independent controlled outcome evidence** (PF-24). The strongest 2026 data are small controlled evaluations (E12-E14, PF-02, PF-15, PF-16).

## Limits
