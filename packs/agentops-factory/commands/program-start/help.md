# Start one bounded program

`gc agentops program start --source-bead ID` snapshots that exact Bead as the
intent, freezes the first observed base commit, and admits the checked
Fable-Mayor → Sol-plan workflow. `--intent FILE` may select an explicit intent
artifact without changing the Bead as the workflow unit. `--max-parallel N`
bounds the semantic work width; it does not lock the moving base branch.
